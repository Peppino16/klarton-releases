# Klarton

*Klares Bild, ehrlicher Ton.* Schlanker Player für Videos, Musik und Bilder unter Windows 10/11.

## Herunterladen

Unter **[Releases](https://github.com/Peppino16/klarton-releases/releases/latest)** die Datei
`Klarton-Setup-<Version>.exe` herunterladen und starten. Installiert wird ohne Administratorrechte.

Der Installer ist nicht signiert: Windows zeigt beim ersten Start eventuell „Der Computer wurde durch
Windows geschützt“ → „Weitere Informationen“ → „Trotzdem ausführen“.

Klarton sucht danach selbst nach Updates (abschaltbar im Menü „⋯“).

## Lizenz

Klarton steht unter der MIT-Lizenz. Es nutzt FFmpeg unter der LGPL v3; der passende FFmpeg-Quelltext
liegt jedem Release bei.
